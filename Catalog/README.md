# Catalog — каталог с фильтрами на Yii2

Пример из проекта корпоративного каталога на Yii2.

## Задача

Реализовать каталог продукции:

- фильтры по категории, цене, бренду;
- сортировка по цене, дате;
- ЧПУ-страницы категорий;
- товары не в наличии — в конце.

## Что внутри

- `ProductSearch` — модель поиска с фильтрами и сортировкой.
- `CatalogController` — контроллер каталога и категорий.
- `CatalogUrlRule` — кастомное ЧПУ-правило.

## Ключевые моменты

- Фильтры через `andFilterWhere`.
- Сортировка через `addOrderBy`.
- Товары не в наличии — в конце через `CASE WHEN`.
- ЧПУ-правило проверяет существование категории.
- SEO-данные для каждой категории.
