# Yii2 Snippets

Обезличенные примеры кода из моих коммерческих проектов на Yii2. Показывают подходы и архитектурные решения. Код заказчиков не раскрывается.

## Что внутри

- **Payment** — полный цикл эквайринга Альфа-Банка: платежи, вебхуки, возвраты, повторные платежи.
- **Catalog** — каталог продукции с фильтрами, сортировкой и ЧПУ.
- **ActiveRecord** — оптимизация запросов, кеширование, связи.
