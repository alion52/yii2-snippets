# Payment — эквайринг Альфа-Банка на Yii2

Пример из проекта мультипаркового сайта на Yii2.

## Задача

Реализовать полный цикл онлайн-оплаты через эквайринг Альфа-Банка:

- инициализация платежа;
- платёжная форма;
- обработка вебхуков;
- обработка статусов;
- возвраты (полные и частичные);
- повторные платежи.

## Что внутри

- `AlfabankGateway` — клиент для API банка: register, status, refund, repeat.
- `WebhookController` — обработка callback от банка: проверка подписи, обработка статусов, защита от повторной обработки.
- `PaymentModel` — модель платежа со статусами и методами перехода.

## Ключевые моменты

- Полный цикл: от инициализации до возврата.
- Проверка HMAC-подписи.
- Защита от повторной обработки вебхуков.
- Логирование операций.
- Статусы: pending, paid, failed, refunded, unknown.

## Безопасность

- Проверка подписи через `hash_equals`.
- Защита от повторного приёма вебхуков.
- Логирование в отдельный канал `payment`.
