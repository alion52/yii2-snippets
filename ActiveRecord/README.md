# ActiveRecord — оптимизация запросов

Пример из проектов на Yii2.

## Что внутри

- `OptimizedQuery` — примеры оптимизации ActiveRecord:
  - eager loading через `with()` для избежания N+1;
  - кеширование результатов;
  - пакетная обработка больших выборок через генератор;
  - связи `hasOne`, `hasMany`.

## Ключевые моменты

- `with()` загружает связи одним запросом.
- Кеш на 1 час снижает нагрузку на БД.
- Генератор позволяет обрабатывать миллионы записей без переполнения памяти.
- Связи с сортировкой через `orderBy`.
